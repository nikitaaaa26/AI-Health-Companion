# AI-Health-Companion
AI-powered health risk analysis platform combining Machine Learning, nutrition analytics, and lifestyle insights to classify users into Healthy, Moderate Risk, or High Risk categories. Built with Python, Scikit-learn, and Streamlit for educational and research purposes

An AI-powered health risk analysis application that combines
Machine Learning, nutrition analytics, and lifestyle data to
provide personalized health-risk insights.

The system analyzes factors such as BMI, sleep, physical activity,
hydration, calories, protein, fiber, and other nutrition-related
parameters to classify users into:

- 🟢 Healthy
- 🟡 Moderate Risk
- 🔴 High Risk

## 🚀 Features

- Machine Learning-based health risk prediction
- Random Forest classification
- Automated feature engineering
- Nutrition & lifestyle analysis
- Prediction probability
- Overall lifestyle score
- Personalized risk factors
- Lifestyle recommendations
- Clean and responsive Streamlit UI
- Explainable prediction insights

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Plotly
- Joblib

## 🤖 Machine Learning

The project uses a supervised multi-class classification approach.

Models explored:

- Logistic Regression
- Random Forest
- Gradient Boosting
- Extra Trees
- HistGradientBoosting

Random Forest was selected as the final model based on comparative
evaluation and cross-validation performance.

## ⚠️ Disclaimer

This project is an educational and research prototype developed
for learning and demonstration purposes only. It is not a medical
device and does not provide medical diagnosis, treatment,
prescription, or emergency medical advice.

Predictions may be inaccurate and should not be used for clinical
or medication-related decisions. Users should consult qualified
healthcare professionals for medical concerns.
